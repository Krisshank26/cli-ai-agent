# Assignment 02 — Website Cloner Agent

## Overview
This project is a conversational CLI agent that follows a step-by-step reasoning loop to turn a natural-language instruction into real output files.  
The assignment asks for a terminal-based agent that can clone the **Scaler Academy** website by generating a working webpage with:

- **Header**
- **Hero Section**
- **Footer**

The final webpage should open in a browser and visually resemble the Scaler website.

## Problem Statement
The goal of the assignment is to build an AI-powered CLI tool that behaves like an agent, not just a one-shot script.  
It should:

1. Accept a user instruction in the terminal
2. Reason through the task in multiple steps
3. Use tools when needed
4. Produce actual output files
5. Generate a working HTML/CSS/JS website clone

The assignment also expects the agent to loop through its reasoning and actions instead of finishing everything in one response.

## Solution Implemented in `script.js`
The `script.js` file implements a CLI agent that communicates with an LLM through a strict step-based workflow:

- **INPUT** — understands the user request
- **THINK** — breaks the task into smaller steps
- **TOOL** — chooses and runs a tool
- **OBSERVE** — reads the tool result
- **OUTPUT** — returns the final response

The script keeps sending the model response back into the conversation so the agent can continue the loop until the task is complete.

## How the Agent Works
1. The script loads environment variables using `dotenv`.
2. It creates an OpenRouter client.
3. It defines helper tools such as command execution.
4. It sends a system prompt that forces the model to reply in JSON.
5. It parses each model response and decides whether to:
   - continue thinking,
   - call a tool,
   - or stop with the final output.
6. When the model requests a tool, the script executes it and sends the result back as an `OBSERVE` step.
7. The loop continues until the model returns `OUTPUT`.

## Key Tool Used
### `executeCommandOnCLI(command)`
This tool runs terminal commands through `child_process.exec`.

It is the main action tool for tasks like:

- creating folders
- creating HTML, CSS, and JS files
- writing website code
- opening or preparing the final project structure

## Why This Solves the Assignment
This solution matches the assignment requirements because it:

- works as a **CLI agent**
- uses a **multi-step reasoning loop**
- supports **tool execution**
- can generate **real files**
- is designed to create a **Scaler-style cloned webpage**
- separates reasoning from execution in a structured way

## Expected Output
The agent is intended to create a project folder such as `scaler_clone` and generate a complete webpage that includes:

- `index.html`
- `style.css`
- `script.js`

The output should be a browser-openable webpage that visually resembles the Scaler website.
